# AI-Resume-Screening-System

##  Overview
This project is an AI-based resume parsing and candidate screening system designed to automate the initial stages of recruitment.

It extracts relevant information from resumes, processes the data using Natural Language Processing (NLP), and evaluates candidates based on their relevance to job requirements. The final output is a structured dataset with candidate scores to assist recruiters in shortlisting.

---

##  Features
-  Resume data processing and analysis  
-  NLP-based text extraction and cleaning  
-  Keyword and skill matching  
-  Candidate scoring and ranking  
-  Structured output in CSV format  
-  Automated shortlisting support  

---

##  Tools & Technologies Used
- Python  
- Google Colab  
- Pandas  
- NumPy  
- Scikit-learn  
- NLP techniques (TF-IDF / text processing)  

---

##  How It Works
1. Resume data is collected and loaded.  
2. Text is cleaned and preprocessed.  
3. Important features like skills and keywords are extracted.  
4. NLP techniques are applied for analysis.  
5. Candidates are scored based on relevance.  
6. Final results are stored in a CSV file.
